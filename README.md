# Ali Jutt Portfolio

A professional GitHub Pages portfolio for Ali Jutt, showcasing projects and development work.

## Live site

https://alijutt-xd.github.io

## Local preview

Open `index.html` in a browser or run a small local web server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Notes

The portfolio automatically pulls repository data from GitHub's public API for the project section.
